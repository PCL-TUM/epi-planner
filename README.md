# EPI Planner

โครงการช่วยวางแผนการรับวัคซีน EPI เป็นเว็บ Static ที่ทำงานในเบราว์เซอร์
ไม่มี PHP หรือฐานข้อมูล ขณะนี้เป็นต้นแบบที่ยังไม่ผ่านการตรวจสอบทางวิชาการ
**ห้ามใช้เป็นวันนัดจริง**
สามารถระบุจำนวนเข็ม PCV เพื่อแสดงในผลลัพธ์และหน้าพิมพ์เท่านั้น
หากเคยได้รับ ให้ระบุวันที่รับเข็มแรกด้วย ข้อมูลเหล่านี้ยังไม่มีผลต่อการคำนวณตารางวัคซีน
ช่องวันที่ใช้ปฏิทินภาษาไทยและปี พ.ศ. เลือกจากปฏิทินหรือพิมพ์ในรูปแบบ `วว/ดด/พ.ศ.`

ตารางวัคซีนหลักอ้างอิงรูปแบบจากเว็บไซต์ตัวอย่างที่ผู้ใช้ให้มา ไม่ใช่หลักเกณฑ์ทางการที่ตรวจสอบแล้ว
ตาราง PCV แสดงวันที่ครบอายุ 2, 4 และ 12 เดือน พร้อมวันนัดเบื้องต้นเป็นพุธที่ 3 ในหรือหลังวันที่ครบอายุ
วันนัดเป็นเพียงข้อมูลเบื้องต้น ไม่ใช่วันนัดจริงหรือตารางฉีดชดเชย และไม่ปรับตามประวัติที่ระบุ
ระบบไม่ตรวจสอบวันหยุด
หากตรงวันหยุด เจ้าหน้าที่ต้องตรวจสอบและเลื่อนไปวันพุธที่ 4 ของเดือนเดียวกันด้วยตนเอง
รวมถึงตรวจสอบประวัติวัคซีนและความเหมาะสมของวันนัด

## พิมพ์ตาราง

เลือกกระดาษ A4 แนวนอนและมาตราส่วน 100% หรือขนาดจริง โดยปิดหัวกระดาษและท้ายกระดาษของเบราว์เซอร์
ตารางขาวดำจะอยู่ในพื้นที่ A5 แนวตั้งครึ่งซ้ายของแผ่น พร้อมขอบ 5 มม. และเว้นครึ่งขวาว่างไว้
ตรวจสอบตัวอย่างก่อนพิมพ์ เนื่องจากการตั้งค่าเครื่องพิมพ์อาจปรับขนาดหรือระยะขอบได้

## ทดลองในเครื่อง

เปิด Apache ใน XAMPP แล้วเข้า <http://localhost/epi_planner/>
Apache ใช้สำหรับทดสอบในเครื่องเท่านั้น ไม่จำเป็นต่อการ deploy
เนื่องจากใช้ JavaScript modules ควรเปิดผ่านเว็บเซิร์ฟเวอร์แทนการเปิดไฟล์โดยตรง

## ทดสอบ

หากติดตั้ง Node.js ให้รัน `node --test tests\schedule.test.mjs` ในโฟลเดอร์โปรเจกต์

## เผยแพร่ด้วย GitHub Pages

1. สร้าง GitHub repository และ push ไฟล์ในโปรเจกต์ขึ้นไป
2. ใน repository เปิด **Settings > Pages**
3. เลือก **Deploy from a branch** แล้วเลือก branch `main` และโฟลเดอร์ `/(root)`
4. บันทึก แล้วเปิด URL ที่ GitHub Pages แสดง

GitHub Pages ให้บริการไฟล์ Static เท่านั้น โค้ดคำนวณจึงต้องทำงานด้วย JavaScript
ในเบราว์เซอร์ ส่วน Git Graph ใช้ดูประวัติการเปลี่ยนแปลงของ Git
